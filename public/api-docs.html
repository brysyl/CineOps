1. Endpoint Overview

The Thermal Alert API endpoint serves as CineOps AI’s high-priority incident dispatch pipeline. When render farm compute nodes exceed calibrated thermal ceilings, this endpoint ingests telemetry signals, logs autonomous load-shedding directives executed by the Gemini 3.6 Flash reasoning bus, and formats a Slack Block Kit payload for immediate channel broadcast.

2. Trigger Conditions

  • Telemetry Threshold Violation: Real-time hardware monitors detect core GPU/CPU temperatures at or exceeding safety limits (Default: 80°C).
  • Control Room Chaos Injection: Operator-initiated chaos engineering drills executed from the Studio Control Room UI.
  • Observability Forwarding: Webhook alert hooks forwarded directly from Grafana Alertmanager or Prometheus rule triggers.
